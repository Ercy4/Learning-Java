Java Beginner Projects

This repo includes simple, functional applications designed to build my understanding of core Java concepts.

## Projects

-Calculator 
  A basic calculator that performs addition, subtraction, multiplication, and division.

-Guess the Number
  A fun number guessing game where the computer picks a number and the user has to guess it.

-To-Do List
  A console-based to-do list app to manage tasks.

-Bank Account Simulation
  Simulates deposit, withdrawal, and balance operations for a simple bank account.

-Grade Calculator
  Calculates average grades and determines letter grades based on scores.

## Technologies Used

- Java
- IDE: IntelliJ IDEA / VS Code / Eclipse
